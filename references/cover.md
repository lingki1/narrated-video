# 封面：单独设计，不是抽一帧

片子里的一帧，是给全屏、连着看的人画的。封面是给另一种人画的：他在信息流里，封面只有 170–360 像素宽，夹在别人的封面中间，他看一两秒就划走。所以封面要**单独构图**：用片子里的同一个角色、同一套图形，重新画一张。

这份做法来自两份调研（封面设计的方法和证据、国内外各平台的规格和裁切）和一条片子上的三轮盲测。

## 一、三张画布

一张 16:9 不够。同一个概念画两遍（横的、竖的），出三种文件：

| 画布 | 尺寸 | 用在 | 字和主体放哪 |
|---|---|---|---|
| `wide` | 1920×1080（16:9）；YouTube 用 ×2 的 3840×2160 | YouTube；各处的 16:9 位置 | 上 70%、左右各让 5%；右下 380×160 不放要读的东西 |
| `land` | 1920×1440（4:3）= `wide` 放在正中，上下各 180 px 只铺底色 | B 站投稿（只传这一张，不点「多比例封面」）、抖音横封面 | 同上，全在中间那条 16:9 带里 |
| `tall` | 1080×1440（3:4） | 抖音竖封面（管个人主页）、小红书、视频号 | 收进正中 1080×1080；底部 10% 和左上角不放字 |

**为什么是「上 70%」**：B 站首页卡片和搜索卡片的底部约 28% 是一条深色渐变，上面压着播放量、弹幕数、时长（实测）；抖音精选占底部约 12%；YouTube 的时长角标在右下角。把字压在底边的封面，字真的被盖掉了。

文件：PNG 或 JPG。B 站按 2 MB 以内出（平涂画的 PNG 只有一两百 KB）；YouTube 电脑端上限 50 MB、手机端 2 MB。

## 二、画面的规矩

**字**
- **2–4 个汉字，最多 6 个，最多两行，最粗的字重**（思源黑体 Heavy）。三份大样本数据都指向「字越少越好」；头部知识区作者也都是 2–6 个字。
- **单字高 ≥ 封面高的 18%**：1080 高的画布上每个字 ≥ 200 px，常用 240–300 px。算法：缩到 168 px 宽时一个字还要有 16 px 以上才读得出。
- 放在上 1/3 或主体旁边。按词断行，不拆词。
- **封面上的字不重复标题**，两样合起来才是一个完整的钩子。国内的习惯是封面放主题词（一两个词，或者「啥是 XX」），标题放钩子句；YouTube 的习惯是图上放一句悬念，标题说清楚讲什么。哪种都行，就是别重复。所以每张封面要写明「配哪个标题」。
- 强调色只给一个词。纯色底上的字不描边；字压在强调色或杂乱的底上才加粗描边。

**画面**
- **大元素不超过 3 个**，排得出第一眼、第二眼、第三眼。通常是：一件正在发生的事（主体）+ 那几个字 + 纯色底。
- **整体要亮**。暗图在数据里一直表现差；亮的纯色底在深色界面和白色界面里都跳得出来。
- 强调色只给焦点那一样东西。
- 画「最紧的那一刻」：绳子绷直、钳子正要合上、东西正在掉。这一刻片子里通常抽不到，所以要单独画。
- 角色靠姿态表达，不用夸张的震惊脸（数据不支持，B 站观众也不买账）。
- 用大小差做戏（一个很大的东西 + 一个很小的东西），用出血和遮挡做层次，代替渐变和景深。
- 配色先算对比度（WCAG 公式），字和底至少 4.5:1。项目里哪两个颜色不能直接配字，写进 `PROFILE.md`。

**承诺要兑现**
- 封面上那件事，片子第一分钟里就要出现。YouTube 的封面测试按观看时长判胜负，骗进来就走的封面在机制上会输。
- B 站明写：封面「刻意隐瞒内容以制造信息差」「无可验证的过度夸张」会限流。

**不能放的**
- 二维码、联系方式、网址。
- 任何平台的账号落款、水印、logo（四家都把别家的标识算导流；一张图要发几家，就什么落款都别印）。
- 别人的商标和角色。

## 三、流程

1. **先想三个不同的概念**，不是同一张换颜色。例如：片子讲的那个主题、片子开头那件事、片子问的那个问题。每个概念一句话写清：图上是什么、哪几个字、配哪个标题。
2. 在片子文件夹里写 `cover.js`（`cover.html` 新建片子时已经带了）：每个概念一个函数，横版、竖版各一套位置。用片子自己的图形和角色画。
3. 出图：`node tools/cover_render.mjs <片子> --safe`，再 `--ratio wide --scale 2` 出 YouTube 用的大图。
4. 检查：`python tools/cover_check.py <片子>`，逐张看检查图（下面的清单）。
5. **找一个没看过片子的人（或代理）只看一眼 320 px 的小图**，让他说：读到什么字、画面上在发生什么、猜这条讲什么、想不想点。答的和片子对不上就改。
6. 把三张连同检查结果给委托人选。说清我推荐哪张、为什么、各配哪个标题。
7. 选定后，在发布包里写清：哪个平台传哪个文件。

## 三点五、盲测里学到的

没看过片子的人只看一眼 320 px 的小图，挑出来的都是作者自己看不出的：
- **画面里是谁在动手，要写出来。** 一只钳子在剪信，看的人不知道钳子代表谁。挂一块写着它是谁的牌子之后才看懂；牌子小了还是会漏，要放大到 250 px 宽。
- **姿势会被读成别的情绪。** 双手高举 + 脸红，被读成「在欢呼」。改成手机贴着嘴、另一只手去够、皱眉、冒汗，才读成「慌」。
- **和底色相近的东西最后才被看见。** 红色的东西压在粉色的底上，他先看到的是旁边的白色物件。换成深色身体 + 浅色描边。
- **只露半截的东西认得慢。** 被画布边切掉一半的钳子，被认成了鸟嘴。整只画进来。
- **平静的字压在出事的画面上，等于没字。** 同一幅画配一句讲道理的话，他说像讲大道理（2.5 分）；配一句正在出事的话是 4 分。
- **封面上别放观众不认识的名字。** 一个他没听过的产品名站在第 1 名的台子上，他以为是别的东西，整张没看懂（2 分）。
- **片子里才成立的比方，封面上会被想歪。** 把主题画成一个比方里的东西，没看过片子的人会想到别处去。
- 他最想点的始终是「正在出事」的那张，不是「给结论」的那张。

## 四、出图前逐条看

- [ ] 三个概念确实不同
- [ ] 字 ≤ 6 个，每个字 ≥ 200 px（1080 高的画布），最粗字重
- [ ] 字和标题不重复
- [ ] 大元素 ≤ 3 个
- [ ] 字、脸、关键道具都在上 70%，没进左右 5% 和右下角
- [ ] 竖版的字和主体都在正中的方框里
- [ ] 缩到 168 px 宽能读字、认主体；120 px 还认得出主体
- [ ] 灰度下还读得出；模糊后剩下的是「一个主体 + 一块字」
- [ ] 垫白底、垫黑底各看一次，边缘都清楚
- [ ] 叠上 B 站信息条和 YouTube 时长角标，没盖住要读的东西
- [ ] 三张并排，眼睛先去的那张就是该推荐的
- [ ] 没看过片子的人看一眼，说得出主题
- [ ] 封面上那件事在片子第一分钟里
- [ ] 没有二维码、平台落款、别人的商标

## 五、工具

```bash
node tools/cover_render.mjs <片子>                      # 每个概念 × wide / land / tall → videos/<片子>/out/cover/
node tools/cover_render.mjs <片子> --safe               # 另出一份画上遮挡区和裁切线的（…-safe.png）
node tools/cover_render.mjs <片子> --ratio wide --scale 2   # 3840×2160（…-wide@2x.png）
python tools/cover_check.py <片子>                      # 每个概念一张检查图 + 三张并排的 _lineup.png
```

`cover.js` 的写法（`lib/cover.js` 负责搭页面、放角色、画安全区）：

```js
import { mountCovers } from '../../lib/cover.js';
mountCovers({
  名字: ({ W, H, tall }) => ({
    bg: '#FFD23F',                    // 底色，纯色
    svg: '…',                         // 角色后面的东西（SVG 字符串）
    cast: [{ x, y, size, facing, expr, handF, handB }],   // 角色的姿势，和 lib/actor.js 一样
    over: '…',                        // 角色前面的东西
  }),
});
```

`tall` 为真时按 1080×1440 摆，否则按 1920×1080 摆（4:3 那张用的是同一套位置）。地面这类要铺到画布外面的东西，往下多画一截，4:3 版才不会露底。

## 六、哪些有数据，哪些只是经验

- **有数据**：字越少越好；暗图差；复杂度太低太高都差；情绪强的图播放多；夸张表情不是必需；封面测试按观看时长判；各平台的遮挡和裁切（实测或官方）。
- **只是经验**：三要素、三分法、留白三四成、先做封面再做视频、一次出三个概念、某种颜色点击高。照做没坏处，别当定律。
- **没有数据**：吉祥物能不能代替真人的脸。
- 公开研究都拿不到点击率，用的是播放量，只是相关；发布这些研究的公司多数在卖封面工具。
