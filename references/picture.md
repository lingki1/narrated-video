# 画面

画面用 HTML / SVG 写，每一帧都是时间 `t` 的纯函数：`window.renderAt(ms)`。渲染器一帧一帧截图，所以可以任意跳着看、分段渲、反复重做，永远对得上声音。不用 `setTimeout`、CSS 动画、`Math.random()`、`Date.now()`。

**先挑画面模板**（`templates.md`）：16 种，从 2D 绘本到聊天记录、白板手绘、数据图表。下面讲的是所有模板共用的内核；每种模板自己的舞台和帮手在 `templates.md` 和 `templates/<名字>/scene.js` 里。

## 内核替你做了什么（`lib/film.js`）

你给它台词、一个模板和一个 `build()`；它负责：按真实配音时长串时间轴、讲述者的话变成逐字出现的字幕、别的声音的话打在卡片里、夜色切换、镜头震动、片尾卡、预览播放、给渲染器的接口。模板决定舞台长什么样。

```js
import { createFilm, el, svgBox, soft, pop, tf, fade, slam, seg, E } from '../../lib/film.js';
import { picture, scene, rise } from '../../lib/templates/picture.js';
const film = createFilm({ lines: LINES, durations: D, template: picture(), voices: { S: { tag: '她' } }, theme: { accent: '#FF8A1F', accentDeep: '#D9650A' } });
const { vo, T, wt } = film;

film.start({
  night: (t) => t >= T.eve && t < T.morn,                    // 夜色
  character: buddyCharacter({ moods }) /* 可选；或自己画的 { mount, render }；物件讲述者也可以直接画进每一幕 */,
  endcard: '<div class="title">保温</div><div class="fine">…</div>',
  fonts: ['400 16px "Ma Shan Zheng"'],                       // 额外要等的字体（手写体等）
  build() { /* 在这里加镜头 */ },
  // 其余选项交给模板，比如 board 的故事钟 clock: { keys: () => [[0, 7 * 60 + 50], …], date, chip }
});
```

旧片子里的 `import … from '../../lib/narration.js'` 照样能用：它等于 `film.js` + `board` 模板。

- `vo.L03.at / .dur`：这一句从几毫秒开始、多长。`film.endOf('L03')`。
- `wt('L03', '按下预约')`：这句里这个词被说出来的时刻。**画面上的东西一律挂在词上，不挂在估的秒数上**；词不在这句里时渲染器会打印警告。
- `film.shot(from, to, node, render)`：一个镜头在画板上待的时间段；`render(t)` 里摆它的零件。
- `film.cue(t, 'msg' | 'tick' | 'bell' | 'alarm' | 'stamp')`：给 `sound.py` 的音效点。`film.hit(t, 强度)`：镜头震一下。
- `T.xxx = …`：自己的时间标记挂在 `T` 上，`sound.py` 从时间轴里读得到。
- `film.talk(t)`：讲述者此刻的响度 0–1，拿来驱动嘴、盖子、灯。
- `film.every(fn)`：每一帧都调用 `fn(t, { night, ending })`，给不属于某个镜头的东西用（页眉、计时）。

入场动作：`soft()`（轻轻升起、淡入，默认用它）、`pop()`（带一点回弹的缩放）、`slam()`（砸下来，全片留给一两处）。

## 舞台（1080×1920）

每种模板的版面不同（board 是「顶上故事钟 + 中间 920×700 画板 + 右下角色」，picture 是整屏插画 + 下方字幕，chat 是一个消息窗口……），共同的是：

- 字幕默认在 y 1252（board）或 1400 左右（其他模板，CSS 变量 `--subs-top`）。
- **关键信息放在 y 220–1500 之内**：平台的标题栏、按钮列、文案会盖住上下两头（`tools/retention_scan.py --safe` 出叠图）。
- 画板里一个镜头只放这句话正在说的东西：一两样，最多三样。说到才出现，**画面不许比声音先露底**。
- 一个镜头对应一段话（10–30 秒），里面的零件跟着词一个个出现。块与块之间换镜头，不用转场特效。
- 第 0 帧要成立（预览页和分享卡片会先显示它）：标题或第一样东西已经在画板上。正式的封面另画，见 `cover.md`。

## 样式

- 配色只有主题里那几个：`ink`、`paper`、一个强调色 `accent`（和深一档的 `accentDeep`）、夜色 `night`。写成 CSS 变量 `var(--accent)`；SVG 里用 `film.theme.accent`。强调色跟着片子的那一样东西走（保温灯就是橙的）。
- 纯色平涂。不用渐变、光晕、多色背景。质感靠硬投影（`7px 7px 0`）、微微歪的字条、粗细对比。
- 现成零件（`lib/film.css`）：`nv-plate`（字条：默认黑底，`.accent` 强调色底，`.paper` 浅底）、`nv-chip`（描边小标签）、`nv-stamp`（图章）、`nv-doc`（一页纸）、`nv-photo`（相片框）、`nv-t nv-serif / nv-sans / nv-num`（大字、数字）。片子自己的零件写在 `style.css`，类名加前缀。
- 夜里的镜头：`el('div', 'nv-shot night')`，深底上用 `.paper` 和 `.accent` 的字条，线条用 `var(--paper)`。
- 字要大：画板里正文 44 px 起，重点 80–150 px。长句子自动缩字号的只有字幕；画板里的字自己算宽度（一个汉字 ≈ 字号的宽度，加左右 48 px 内边距），别出框。

## 角色

- 现成的：`lib/buddy.js` 的 `buddyCharacter({ look, moods })`——软糖身体、会眨眼、说话时比划、片尾挥手。`look` 改配色和头饰；`moods` 是 `[时刻, 表情, 特效]` 的列表。
- 自己画：任何有 `mount(svg层, film)` 和 `render(t, film, { night, ending })` 的对象都行。讲述者是物件时就画那个物件，给它两只眼睛和一个会动的地方（盖子、灯、指针）跟着 `film.talk(t)` 动，再给三四种表情按时刻切换。
- 角色是讲述者，不抢戏：站在右下，动作小。片尾走到中间。（picture 模板里讲述者常常直接画进每一幕：见 `templates.md` 的模板规矩。）

## 讲述者亲手做事（`lib/actor.js`）

讲述者不能永远站在角落讲、让画面自己动：它要和画面上每一样会动的东西有关系，比如亲手把它画出来。讲述者是个角色时，**每一幕先想它亲手做什么**，再画别的。

- 怎么接：`const sc = makeSc(film)`（镜头不动，画面坐标 = 角色坐标），`film.start({ character: actor(film, { look }) })`。每一幕的 `render(t, s)` 里算出这一帧的姿势，最后 `act(pose)`。没人指挥的帧才退回 `at()` / `mood()`。
- 姿势：`{ x, y, floor, size, facing, rot, sx, sy, feet, handF, handB, prop, propRot, tip, expr, fx }`。现成的：`walkPose(t, a, b, x0, x1, 地面, 大小)` 走、`hopPose` 跳、`runPose` 原地跑（地面往后滚）、`pen(tip)` 在齐胸高的墙上写、`penUp(tip)` 举着笔在头顶上写、`drawPaths(组, t, a, b)` 一笔一笔画出一组线并返回笔尖。手里的东西：`prop: 'pen' | 'scissors' | 'stamp' | 'magnifier' | 'broom' | 'tweezers' | 'wrench'`；帽子按时段：`PROPS.detective.push([from, to])`。
- 搬东西：东西的位置由同一个时间算，手放在东西底下（`handF / handB` 给世界坐标）。扛在头顶走、放下、往上扔、推着走、拉着走、从地里拔出来，都是「东西的位置 + 两只手的位置」。
- **它够不着的东西别让它伸手**：0.55 大小的角色约 230 px 高，手能到的范围是肩膀上下约 150 px。要碰更高的：走过去、踩凳子（`stool`）、爬梯子（`ladder`）、跳起来、或者扔上去。第一稿常犯的错是一条胳膊伸过半个屏幕——`node render.mjs videos/<名字> --sweep` 会把每个「手离肩膀太远」的时刻列出来（数字 300 以内正常，400 以上去看那一帧）。
- 上半屏留给它**不用碰**的东西：标题、说明卡片、图表、对照表；它碰的东西放在地面到头顶这一带。只在脚边演、上面一大片空，画面会显得小气——把说明放上去。
- 两幕交叠的那几帧，新旧两幕都在调 `act()`：后画的（新一幕）整个替换，不合并（合并会让旧一幕的手伸进新一幕）。
- 写每一幕之前，把那一句台词原文再读一遍：凭印象写，动作会和台词的先后对不上（`wt()` 找不到词会报警告，但顺序错了它不知道）。
- 常用的画法在 `lib/parts.js`：色板、`tx / rect / line / bubble / phone / doc`、模型盒子 `modelBox` 和带帽子的 `bot`、`person`、马和车、梯子凳子，以及 `rise / pop / fadeIn / fadeAway / place / type / count`。

## 横屏（16:9）

要发横屏平台（YouTube、抖音横屏 / 精选、B 站）时，同一份画面可以直接出横版，不用重画：

```js
createFilm({ …, size: [1920, 1080], view: [-420, 396] })   // 画面坐标不变，只是换了一扇更宽更矮的窗
```

- 场景照旧画在 1080 宽的中间一栏里（地面 y = 1300 上下）。横屏的窗口是 x −420…1500、y 396…1476：地面和背景自动铺满（`bg()`、`floor()` 认得窗口），角色和道具大小不变——在矮了一半的画面里反而更大。
- 两边各多出 420 宽的「翼」：`heading()` 在横屏里自动排到左翼（分词折行）。竖屏里因为顶部被占而没有标题的幕，横屏可以单独给一个（`isWide() ? heading(…) : ''`）。
- **章节进度条**（长片必备）：`film.start({ chapters: [[标签, 这一章第一句的 id, 小字（如年份）], …] })`，画面最底下一条，按每章的时长分段，已经播过的部分填强调色，标签放不下会自己缩字号。有了它字幕自动上移一点（946px）。标签用观众认得的东西（各时期的软件名），不用行内的章节名；右翼不要再放目录（试过，不如放在底部像进度条那样）。只在横屏显示。
- 窗口上沿是 y = 396：竖屏里画在更高处的东西（顶部的图表、日期牌）在横屏里要缩小下移，用 `isWide()` 分开写。出处小字在横屏里自动贴到地面线下（`note()`）。
- 「出画」的坐标：`walkPose` 的 −100 / 1180 这类数字在横屏里自动推到真正的边缘之外；别的东西飞出去、滚进来，用 `off(x)`（`actor.js`）包一下同样的数字。铺满宽度的东西（传送带、水面、路上的虚线）用 `ST().x`、`ST().w`、`edge()` 算。
- 字幕在底部居中（一条能放三十多个字），别的声音的卡片在顶部居中，片尾居中、讲述者站在字下面。出处小字（`note()`）贴在地面线下、字幕上面，别写太长。
- `render.mjs`、预览页、拼图工具都跟着片子的尺寸走。想留竖版：`scene.js` 里用一个开关（比如 URL 带 `?tall`）决定传不传 `size / view`。
- 横屏才会暴露的坑：`getCTM()` 给的是画面像素，不是场景坐标（`drawPaths()` 已经加回窗口的偏移；自己用时记得加）。

## 画面别简陋：镜头、布景、阴影、素材（`lib/look.js`）

一条十分钟的横屏科普片，看过的人说文案通俗易懂，画面却太简陋。找一个代理只看画面挑毛病，它排的头三条是：**主体小**（小人约 260px 高，戏挤在地平线上一条带里，右边三分之一空着）、**一个机位到底加硬切**、**背景只有一层，东西像贴纸飘着**。两路上网调研的结论一致：不用换工具，差在构图、层次和运动；给代理写的同类规则里的数字是「主体占画面宽 60–80%、至少三层、每个画面 6–10 个视觉角色、入场 0.4 秒退场 0.25 秒」。整套做法收在 `lib/look.js`，横屏长片默认用它。

```js
import { look2, iconKit } from '../../lib/look.js';
import { ICONS } from './icons.js';                       // tools/icons_pull.mjs 生成
export const icon = iconKit(ICONS);
const sc = look2(film, { icon });                         // 代替 makeSc(film)，场景照旧写
sc(from, to, { bg, cam: [[from, [20, 760, 1080, 1330]], [wt('L01', '某个词') - 200, [540, 730, 1420, 1330], 600], [wt('L01', '另一个词') - 200, null, 800]],
               svg: `${bg(K.pinkL, 'room')}${floor(FL, '#F5C9D7')}…` }, render);
```

- **镜头**：`cam` 是关键帧 `[到达时刻, 矩形 | null, 移动毫秒 = 700]`。矩形是「画面要装下的那块场景」（场景坐标 `[x0, y0, x1, y1]`），`null` 是全景。不给 `cam` 就只缓推 4%。镜头永远不出已经画好的范围；讲述者那一层跟着同一个镜头走。到达时刻挂在词上（`wt()`）。
  - **能推多近看高度**：16:9 的画面矮，一块场景越高越推不近——高 470 能推到 1.8 倍，高 700 只有 1.2 倍，高 900 推不动。所以说明性的东西（大字、卡片、标牌）别放在离地面五六百像素的高处，放到「头顶上方一两百像素」或者主体旁边；真要放高处，就分成两个镜头：先全景看它，再推到地面上的戏。
  - 一幕两三个关键帧就够：开场框住正在说的东西 → 说到别处时移过去 → 要看全貌或大字时拉回 `null`。别每一幕都是同一种推法。
  - 一幕开场就推近时，这一幕和上一幕里讲述者的位置可以不连续（转场是从它身上扩开的一个圆，盖得住）。
- **布景**：`bg(色, '布景名')`。八套：`room` 房间、`office` 工作间、`server` 机房、`stage` 领奖台、`field` 野外、`city` 街道、`station` 地铁站、`paper` 点阵纸（讲图表用）。颜色全由这一幕的底色推出来（深一档、深两档、浅一档），不描边、不抢戏；远景只跟镜头走一部分（视差），云会飘、机柜的灯会闪、纸屑会晃。地面有一道深色的沿和三条色带。`sc.set('room')` 设一整块的默认布景，个别幕在 `bg()` 里另指。
- **两翼的家具**：传了 `icon` 以后，每套布景在左翼（有的在右翼）自动站一两件物件（绿植、文件柜、树、礼花）。这一幕的翼上有自己的东西时写 `bg(色, { set: 'room', bare: true })`。
- **物件素材**：自己画的方块圆圈撑不起「东西很多」的画面。`tools/icons_pull.mjs` 从开源图标集里按名字取物件、把每个颜色换成调色板里最近的那个；`icon(名字, x, y, 大小)` 画出来自带墨线（`(x, y)` 是底边中点）。来源和许可见 `kit/README.md`「素材」。**带品牌标志的图标一律不取**；讲述者和片子的主比方（马、门）仍然自己画。
- **硬阴影**：`look2` 打开后，`rect()` 给浅色、带墨线、够大的面板自动加一块平涂的影子（偏右下 9px，墨色 14%）；落地的东西用 `ground(x, y, 宽)` 加一块扁椭圆。都是平涂，不是渐变。
- **玻璃上的字**：`heading()` 和 `note()` 被搬到不跟镜头走的一层，底下垫一块和底色相同的板。标题读完缩到角上，镜头推近时让开；出处固定在右上角，长的自动折成两行。想让别的东西也留在玻璃上，给它 `data-hud="1"`。
- **转场**：新的一幕从讲述者站的地方一个圆扩开（0.52 秒）。前后两幕同底色同布景时几乎看不出来，正好当硬切用。
- **金句上屏**：`sc.gold('L29', '起头的几个字', '要上屏的那一句', { top, dx, size, untilWord })`，写在每块 `build` 的末尾。念到起头那几个字时，一块黑底带强调色硬影的牌弹在画面上方（在玻璃层，不跟镜头走），带一声盖章；默认留到这句话说完，句子后面还有话就用 `untilWord` 让它在那个词之前收。每一处都要抽一帧看它压没压住这一幕顶上的标题和卡片，用 `top` / `dx` / `size` 挪开；幕里本来就有同一句话的字幕牌时不要再叠一块。
- **字幕句末不带标点**（内核默认）：一条字幕结尾的逗号、句号、问号、冒号、顿号都不显示；句子中间的标点照常。台词本身不用改，标点还要留给合成声音断句。
- **字幕和进度条**：`film.start({ subs: 'karaoke' })` 让整句先暗着出现、念到哪个字哪个字亮（原来的做法是字一个个冒出来，黑框大半时间是空的）；进度条只亮当前这一章，顶上一条细线走到播放位置。
- **做完找别人挑**：自己看自己的画面看不出简陋。抽三十来帧拼成图，交给一个代理只看画面（扮「常看科普动画的观众 + 做动效的设计师」），问它「简陋在哪、按影响排序、每条怎么改、哪些改一次工具全片受益」。把约束（平涂、不用渐变、不出现第三方标志）和现在的动法如实告诉它。
- 预览页是在手机上实时跑的：描边别用滤镜（镜头一动整幅重算），`icon()` 用的是「底下垫一份全黑加粗」的画法。一个小脚本量一下每帧脚本耗时，桌面上 1–3 毫秒算正常。

## 讲机制的画面（科普片）

- 一个机制一幕，这一幕要把机制**演出来**：聊天记录整段飞进模型、窗口满了最旧的被剪掉、资料变成地图上的点、离问题最近的几个点飞进窗口、一圈一圈转的循环、排行榜往上爬、清单一条条打勾。只出字和线条是偷懒。
- 每一幕有一个主动作，跟着词发生；其余的东西安静。
- 长片（几十幕）按块拆文件：`parts.js` 放这条片子共用的画法和讲述者的走位（`at()` 站位、`mood()` 表情、`point()` 指、道具时段），`b0.js … b7.js` 一块一个文件，`scene.js` 只负责拼起来。

## 画东西

日常的东西用 SVG 基本形状拼：圆角矩形、圆、几条线。画法统一：粗描边（7–11 px）、圆头、平涂填色、一处强调色。认得出是什么就够了，不追求像。复杂的图标宁可换成一个词。

## 边写边看

```bash
node render.mjs videos/<名字> --stills 0,5000,20000
python tools/contact_sheet.py videos/<名字>/out/sheet.png videos/<名字>/out/stills/<名字>-*.png      # 一张图看十几帧
```

每个镜头至少抽一帧「零件都出齐了」的时刻。看五件事：有没有出框、有没有互相压住、深底上的字看不看得清、字幕有没有压到角色、卡片有没有盖住不该盖的。

```bash
node render.mjs videos/<名字> --times     # 每句台词从第几秒开始（挑静帧用）
node render.mjs videos/<名字> --sweep     # 不截图把整条时间轴走一遍：页面报错、被拉长的胳膊
```

长片先 `--sweep` 再抽帧：几十幕里哪一帧会抛错，靠抽帧撞不到。配音换成真录音之后时间轴会整体变快，动作要重新抽一遍。出处小字放在 y ≤ 1380，再往下会被字幕盖住。

## 常踩的坑

- 命令行里用 heredoc 写带反斜杠或引号的代码会被吃掉字符：长文件直接写文件，不走命令行。
- 字体按字符范围加载：屏幕上会出现的每一个字都要在加载字体之前出现在页面里（内核已经把台词、模板的 `labels()`、片尾算进去；你在 `render()` 里才生成的新字要自己提前放一份）。
- **不要用 `scale(0)` 藏东西**，也别在 `build()` 里量尺寸：见 `templates.md` 末尾的坑（Chromium 不会重排一开始被缩没了的 SVG 字）。SVG 元素上 `style.transform` 会盖掉 `transform` 属性，带位置的组外面再包一层再做动画。
- 引擎在 `build()` 之后才知道每个字的时刻；`wt()` 只在 `build()` 里和之后调用。时钟的 `keys` 写成函数。
- 手机上 1080 宽的画布要包在 `position: fixed; overflow: hidden` 的盒子里，否则整页会被缩小（预览工具已经这样做）。
- 浏览器面板不在前台时动画不走帧：检查画面一律用渲染出来的静帧，不靠截屏。
