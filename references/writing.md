# 写稿

顺序：先定骨架（一），按块把事讲够（二），让人闭着眼也看得见（三），再打磨那几个笑点（四），最后才放流行语（五）。句子最后改。
**第二部分管全局。** 第四部分只管笑点怎么写，不许拿它把稿子切碎。

这些规矩是一条一条被否出来的：讲课腔听着像 AI 写的；撒口语词显得刻意；一句顶一句地抖包袱，太短、太追求戏剧性，看完没有体验。量过二十来篇真实的好稿子之后才知道差在哪（数字见第二部分）。

## 一、骨架：从一件事出发，不从一个观点出发

「观点 → 证据 → 原理 → 结论」是讲课的骨架，怎么换词都是讲课。

1. **先写一句话**：看完这条片子，观众会记住哪一件事，或者去做哪一件事。只留一件。
2. **每个要讲的道理换成一件出过的事。** 问「发生了什么」，不问「为什么」。找不到事的道理，这集不讲。
3. **讲的人低一头。** 他是当事人（搞砸的、想错的、不懂的是他），不是讲师。正经话交给画面，或者让别人说。
4. **用「但是 / 所以」把事串起来。** 两件事之间只能填「还有 / 然后」的，删一件，或者找出真正的因果。
5. **结尾是「我变了」加回扣**，不说「所以说 / 总之」。
6. **最后才看 AI 味，而且把它当症状。** 看到「不是 X 而是 Y」、三项排比、段末总结句、一串抽象名词，不要换词，回头问这句底下那件具体的事是什么；有就写那件事，没有就删。

## 二、体验：按块写，把一件事讲够

体验的单位是块，不是句。量出来的差距：

| | 被否的稿子 | 好稿子（讲解、情感、幽默三类） |
|---|---|---|
| 一件事讲多长 | 16–18 秒，约 60 字 | 40–75 秒，150–290 字 |
| 句子平均 | 8–9 字 | 20–37 字 |
| 逗号之间 | 4–5 字 | 7–11 字 |
| 8 字以内的句子 | 51–68% | 0–9% |
| 换说话人 | 3 秒一次 | 0 次，别人的话由讲的人转述 |
| 笑点 | 7–11 秒一个，停下来等 | 调味，挂在句尾，说完接着讲 |
| 对观众说「你」 | 0 次 | 每 200–400 字一次 |
| 最后一句 | 包袱 | 平静的陈述、回扣、复现的一句话 |

1. **一条片子只讲一件小事。** 开头 15 秒交代：谁、在哪、几点、出了什么事、我当时什么反应。不要求好笑，不要求「钩子」。
2. **一块讲一件事，讲满 40–75 秒、150–290 字。** 两分钟最多 3 块，三四分钟 4 块。明明一句能说完的地方，偏要讲七八句——观众是在这里进到场景里去的。时长跟着内容走，不为时长砍内容。
3. **句子**：句均 20–30 字；逗号之间的小句平均不低于 7 个字；8 个字以内的短句不超过 15%，而且紧跟在长句后面。
4. **一个声音讲到底。** 别人的话由讲的人转述，带「她说」，引语是完整的句子。另一个声音全片最多开口两三次，只留给最要紧的那两句。
5. **对着「你」说。** 第一块结束时一次（你大概也……），结尾一次。片中角色互称的「你」不算。
6. **讲的人在场。** 至少两句「我当时怎么想的」，其中一句是他想错了。
7. **细节小而准，像真的**：钟点到分、次数用个位数、东西有牌子之外的特征（三升的、用掉一半的）。有一处让人说「这个我也干过」。为了效果造出来的大数（五个省、三万人）是在告诉观众这是编的。
8. **块和块之间有一句专门的过渡**（时间词、一个问句、复现的一句话）；每 150–250 字有一句喘气的话（不带新信息，只是他的一声反应，或把刚才那句换个说法）。
9. **最重的那一幕占全片两成上下，写得最慢。** 里面不放笑点，最多在这一段最后一个小句自嘲一下。
10. **最后一句是平的。** 不用包袱收尾，更不许包袱后面再补一个。要带的信息（账号、产品）在倒数第二句平着说。

**写完量一遍**：`python tools/tts/script_measure.py videos/<名字>/lines.js`，再手数每块的秒数和笑点的位置。数字写进交付的话里。

## 三、画面感：闭着眼睛听也能看见

人听故事时一直在追踪谁、在哪、几点、为什么；每换一次都要重新搭一次现场。

1. **定一个现场。** 全片的事放进同一段时间、同一对人、固定的地点，每件事标上钟点。
2. **先落地，再出事。** 时间地点塞进动作句里，不单独成句。
3. **逐句过镜头。** 这句话摄像机拍得到吗？拍得到的句子里要有一个动作或一件指得着的东西；每场只留一两样，挑后面用得上的。
4. **引语三件套**：谁 → 怎么来的 → 原话。
5. **耳朵听不见的东西要翻译**：括号、截图、表情、撤回。靠它们的笑点，第一次明说，之后用一个词指代。
6. **名字钉死。** 「他」和「她」同音，全片只留一个 tā。只有一个「我」。
7. **在同一个现场里加码。** 事情按钟点往下排，一件比一件深一层。把两件事对调，听的人应该觉得顺序不对。
8. **抽象的话只放三处**：每块之后的一句评、讲「为什么」的那一段、全片最后几句。术语先变成东西再出现。数字只留两三个。
9. **闭眼验收。** 只听不看；听完说不出「谁、在哪、手里拿着什么」的段落就是没写好。

## 四、笑点：只管那几个怎么写

1. **先有态度再有事。** 每件事先问「难 / 怪 / 怕 / 蠢在哪，对我」。笑点落在讲的人那一刻的心思上（自我感觉良好而不自知，或者老老实实吃亏），不落在「我们这类人」上。
2. **列假设，打掉一个。** 一句话说完，把听的人此刻默认的东西列出来，挑一个打掉。第一个想到的是所有人都会想到的那个，多写几个再挑。
3. **笑点是长句的最后一个小句，不单独成句。** 前面二十多个字老老实实交代，最后 8–15 个字翻过来。说完不停，下一句接着讲事；最好让上一个笑点变成下一个的铺垫。
4. **好笑的几种来法**：一本正经地推理出一个错的结论；把小事做得太较真；小而准的数（十一遍，不是一万遍）；让别人一句话戳破，由讲的人转述；同一个说法用两次，第二次换了意思；见识有限的讲述者认真地理解世界（电饭煲眼里的微波炉）。
5. **密度**：按一件事连着讲的幽默稿量，大约每 100–180 字一处；全踩在同一件事上才可以再密。笑点的字数占全片一成上下。
6. **自查**：把所有笑点小句删掉，剩下的还得是一个讲得通的完整故事。
7. **不做的**：方言、唱、靠语气的反讽（合成声音会念成真心话）、占便宜的称呼、谐音（听不出是哪个字）、拿观众和任何一类人开涮。

想做一句顶一句的对口段子（相声式）时：那是另一种片子，短、密、戏剧性强，适合三十来秒的梗片，不适合要人「有体验」的片子。

## 五、流行语：每次都查，不凭印象

- 模型的知识有截止日期，流行语几个月就换一茬。**每条片子写稿前重新查**当下还活着的说法，查到的要有日期；查不到最近三个月证据的当过气处理。过时的梗比没梗更糟。
- 优先用这群观众圈子里自己的说法，其次才是通用流行语。
- 流行语不当包袱：可以当铺垫（观众认得，省字），好笑的必须是它在这个场景里造成的后果。演出来、拐个弯、或者一本正经地说。
- 避开：带品牌名的、绑定明星和真人的、歌词、挑动对立的词、侮辱性的词、官方点名的烂梗。
- 查的时候顺便看这个圈子有没有新出的规定或大事——刚出过事的话题不拿来开玩笑。
- 读不到一手帖子（要登录的平台）时只能靠媒体转述；这一点要在交付时说明。

## 六、科普讲解：把一个东西讲透，而不是报一串名字

一条给普通人讲技术概念的片子，第一版两分多钟塞了六个阶段，被否了：太短；没有解释，不会的人看完一头雾水，会的人觉得浪费时间。重做的规矩：

- **先拆成一串小问题，沿一条链走**（回形针的做法）：每一段回答一个问题，回答完留下的麻烦就是下一段的问题。名词出现的顺序跟着问题走，不跟着时间线走。
- **一个概念四步：是什么 → 为什么需要 → 怎么运转 → 它留下的新麻烦。** 「怎么运转」那一步必须有一个具体例子，最好是观众自己碰到过的（「聊得越久越忘事」→「其实每次都把整段聊天重新念给它听」）。
- **概念句和例子句交替。** 说完一个结构，马上给一件具体的东西：几千字、200 多个功能、从三十名开外到前五。
- **给不会的人一个比方，给会的人一个细节。** 比方用日常里的东西（开会的纪要、地图上的坐标、轮班的工人）。细节：原文里的数字、原话、实验结果——每一条都查一手出处，记进这条片子 `docs/` 里的表里；查不到原文的写「转述交叉确认」。
- **时长跟着概念数走。** 一个概念讲透大约要 45–90 秒；五六个概念就是 6–9 分钟。讲不完就砍概念，不压缩解释。科普的一般长度 5–10 分钟（衣戈猜想：一两分钟讲不清一件事）。
- **人名、日期、出处写在画面上，口播只说必要的。** 外文人名合成声音念不准：用中文常用译名，或者口播不念、只放画面。
- **用自己当贯穿的例子**（讲述者是产品时）：每一段都回到「在我这儿是怎样的」，只说真有的功能，引用原文要逐字核对。

同一条片子的后几轮又补了几条（起因：按行内的技术栈排了路线，普通观众一个名字都对不上）：

- **代表物用观众自己用过的。** 给每个阶段挑代表时，问的是「看的人手机里有没有它」，不是「行内最有代表性的是谁」。行内的工具、框架、论文名只上画面当出处，不进口播。国内外各给一个，观众对得上号。
- **每个被点名的东西都要承担一件解释的活。** 只为了凑时间线、凑「国内外都有」而报的名字，删。几件东西之间用「但是 / 所以」接，不用月份接。
- **词先落地，再定死。** 第一次出现就给意思，之后同一个东西只有一个名字；会被数的东西每次都用同样的词、同样的顺序，每讲到一样报一次「这是第几样」。一条片子里观众要记的新词不超过三四个。
- **一个例子用到底。** 第一段用过的例子，后面每一段接着用（接着问、接着办、办到一半被拦下来），不换场景。真事（新闻里别人出过的事）另算，那是证据。
- **一条线从头牵到尾。** 全片的结论要在前面埋（「这一点你先记着」）、在最重的一幕里出事、在结尾收；结尾答的必须是这条线，不是临时换的另一个道理。最重的那一幕篇幅给够。
- **耳朵听不见标点。** 合成声音不念引号、冒号、分号：嵌在句子里的原话，用「她还特意说了一句」这样的话带出来，原话后面另起一句；「想：…做：…看：…」这种靠冒号的结构改成「先想一步，…然后动手，…」。同音的代词（她 / 它）只留一个，另一个一律说名字。新造的词查同音（「闸机」听着像「炸鸡」）。
- **比方别用过头。** 比方里的每一句都得在比方里说得通；一条片子一个主比方，别再叠一个。
- **正反两边都给够。** 说一边是关键的时候，承认另一边也在变；举一家公司的说法，写明是它自己说的。

科普长片最容易输在开头：第一句只是报了一条快讯，前十秒没有抓住人的东西，也没说清这条片子的核心。开头照下面几条写（讲一件小事的短片仍按第二部分第 1 条，不硬找钩子）：

- **第一句是一件出了事的事，不是一条快讯。** 「谁家出了什么、排第几」是资讯号的起手式，观众没有理由停。把全片最重的那件真事的**结果**提到最前面，用现在时、不带日期起头，日期、出处放在第二句和画面上。前 3 秒要让人知道「要出事」，前 10 秒要让人知道这事和自己有关。
- **30 秒之内用一句话说出「这条只讲什么」。** 这句话里要有全片的主比方，而且比方里的东西要先出场再被叫出名字，不能空降。句式越短越好。之后的报幕（走哪几站）不超过一句。
- **引别人的原话当证据时，前后说的必须是同一件事。** 先举了一个例子，紧接着放一段原声，原声说的却是另外几件事，听的人会觉得前后不搭。原话数了几样，后面就交代几样；例子换成原话里说的那件事，别拿另一件事垫场。
- **开头只给结果，原因留到中段；结尾回到开头那件事。** 中段讲到这件事时接一句「开头那件事，现在可以细说了」，把「为什么」讲透；最后几句先回到开头，再收全片。开头抛了问题、结尾不答，观众会觉得被钓了。

## 七、金句：让人想截图的那一句

科普长片容易写得太温吞：本该一句话钉住、让人想截图的地方，被「说白了」「所以它」「我猜」这类注水词稀释了。第一部分第 6 条说排比和段末总结句是「AI 味」的症状，这一条不矛盾：那里防的是底下没有事的空话，这里要的是把已经讲透的事用一句话钉住。

- **放在哪**：每一块讲完之后的那一句评、全片的开头和结尾。一块一句，最重的那一幕里只摆事实不下结论。十分钟的片子十来句是上限，连着三句就挤了。
- **怎么写**：用这一段里已经出现过的东西，不另起比方；对仗但口语，每半句不超过十二三个字；说的是一个判断，不是把上一句再说一遍。
- **耳朵能听清**：同音字查一遍；多音字尽量避开；句式别和全片别的金句撞（同一个句式一条片子里用了四次就腻了）。
- **不说过头**：金句最容易把话说死。「骗不了」「永远不会」这种绝对的说法，事实多半撑不住，改成事实撑得住的那一句。留着的保留（「据估算」「很可能」「按它自己的说法」）是事实的一部分，不算注水；该砍的是「说白了」「说出来你可能不信」「我猜」「可能不对」这类只表示客气的词。
- **别人给的狠句子先过四关再用**：事实对不对；有没有拿真人、别家产品、某一类人、观众开涮；是不是太粗或者在吓唬人；是不是又起了一个新比方。过不了的，留下它的意思，改写进片子已有的比方里。讲述者自己的身份也要顾：它说出口的话不能拆自己的台。
- **委托人点了名的句子，先原样用。** 指定的句子默认原样进稿子，只动会出事的字（事实、真人、还没解释过的词）；动了哪几个字、哪一句没用，放在回复最前面一句一句说，别埋在表里。把它改写进自己的比方再交上去，对方听完会问「我的句子呢」。风格上的不喜欢（多了一个比方、不够克制）不是改它的理由。
- **照样送审**：改完交给别的代理，问它每句「只听一遍立不立得住、有没有说过头、像不像人会说的话、密度」。
- **上屏**：念到金句时把它打在画面上（`picture.md` 的 `sc.gold`），观众截图的就是那一帧。
